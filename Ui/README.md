# Data Structure Project UI

This directory contains the Flask-based interface for the social graph project.

## Pages

- Dashboard
- User analysis
- Path analysis
- Distance analysis
- User and friendship management
- Connected groups and degree ranking
- Graph visualization
- Extended network insights

## Run

```bash
python3 -m pip install -r requirements.txt
python3 app.py
```

Open `http://127.0.0.1:5000`.

The current files implement the interface layer only. Data-processing operations can be connected later without changing the page structure.
